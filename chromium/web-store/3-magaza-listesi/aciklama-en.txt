IP Critical Scorer helps SOC analysts check IP reputation on log, SIEM and ticket screens without switching tabs.

How it works
• Select an IP address on a page; an “IP’yi sorgula” (look up IP) button appears next to it.
• Press the button and the AbuseIPDB result appears in a small card on the same page.
• Selecting text never sends a request; a lookup happens only when you press the button.

The card shows
• Abuse confidence score (0–100) and risk level
• Number of reports in the last year and how many distinct sources reported it
• Last report date, country, ISP, usage type, domain
• Tor and whitelist status
• A link to the AbuseIPDB details page

Features
• IPv4 and IPv6, including notations such as 8.8.8[.]8 and 8.8.8.8:443
• Private and local addresses (10.x, 192.168.x, 127.x, fe80:: and others) are never sent; the card explains the address type instead
• “Copy for Excel”: copies the result as one row, with your note, in the columns and order you configure for your own sheet
• Bulk lookup: query every IP in a log line or table at once and copy all rows to Excel
• Lookup history: today's lookups stay in your browser; select and copy them in one go or download CSV
• Keyboard shortcuts: select → Alt+Shift+A → quick note → C, no mouse needed
• Remaining daily AbuseIPDB quota shown on the card
• Optional: previously looked-up IPs are highlighted on pages in their score colour
• Works inside iframes; settings can be shared with your team as a file
• Caching and respect for AbuseIPDB rate limits
• Runs only on sites you enable
• Light and dark theme, keyboard shortcut (Alt+Shift+A)

Requirement
Scores and report details need an API key from a free AbuseIPDB account (1,000 lookups per day). Without a key, the card links to the AbuseIPDB details page.

Privacy
Only the IP address you select and your API key are sent, to api.abuseipdb.com. Page URLs, page content and cookies are never sent. No telemetry.
