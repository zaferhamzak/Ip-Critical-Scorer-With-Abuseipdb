IP Critical Scorer

AbuseIPDB API anahtarı (isteğe bağlı)

Anahtar yoksa kart yalnızca IP doğrulamasını ve AbuseIPDB detay sayfası bağlantısını gösterir. Ücretsiz bir AbuseIPDB hesabıyla alınan anahtar (günlük 1.000 sorgu) girilirse skor ve rapor bilgileri resmi API üzerinden gösterilir. Anahtarı AbuseIPDB hesabınızda Account → API bölümünden oluşturabilirsiniz. Anahtar yalnızca bu tarayıcıda saklanır ve yalnızca api.abuseipdb.com adresine gönderilir.

Durum: yükleniyor…

Rapor dönemi

Kartta gösterilen rapor sayısı ve son rapor tarihi bu dönemi kapsar. AbuseIPDB API en fazla 365 gün geriye gitmeye izin verir; daha eski raporlar için AbuseIPDB sayfasını açın.

Önbellek

Aynı IP bu süre içinde tekrar sorgulanmaz. Önbellek tarayıcı kapanınca silinir.

Site erişimi

Eklenti yalnızca izin verdiğiniz sitelerde IP seçimini izler. Sayfa içeriği veya URL hiçbir yere gönderilmez.
